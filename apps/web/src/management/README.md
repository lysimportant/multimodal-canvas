# 后台与个人资源工作台

`ManagementPage` 只承载仍由 Canvas 管理的资源、任务、审计和系统状态。身份、分组和费用由 New API 统一处理；本模块不提供注册、密码、邮箱、用户邀请或邮件投递管理。

## 页面与边界

- `/admin` 展示资源与任务概览，不依赖旧用户管理或邮件服务字段。
- `/admin/resources` 展示资源归属分组；`/admin/users/:id/resources` 是现有前端资源详情路径，归属资料读取 `/v1/admin/resource-owners/:id`。
- `/resources` 只读取当前用户资源，不发送可伪造的 `ownerId`。
- `/admin/runs` 与 `/runs` 只观察已有任务，不因打开详情或轮询自动重试生成。
- `/admin/audit` 只展示服务端脱敏审计摘要；`/admin/system` 只展示 API、资源存储和任务队列状态。
- 所有查询键同时包含当前登录用户和目标资源范围。身份变化时外层以用户 ID 重挂载页面，迟到结果只能进入旧身份缓存。

权限由服务端逐请求校验。隐藏导航项不能替代授权，前端也不保存 New API Key、PAT 或长期访问令牌。

## Ant Design 迁移边界

本轮为 P1 管理模块迁移，仅修改本目录；不改请求协议、权限、查询键、共享组件、根 Provider 或依赖。基线为分支 `codex/generate-to-new-node`、提交 `a22b223`，Node v24.12.0、pnpm 11.19.0，原有 3 个测试文件共 18 项通过。依赖已安装为 Ant Design 6.6.5，不另建组件引擎。

- 通用按钮和文本输入使用共享 `@multimodal-canvas/ui`；按钮的 `type` 仍是原生 HTML 语义，保存与搜索显式指定 `submit`。本模块当前没有 textarea 或文件上传输入。
- 筛选与版本选择使用真实 `Select`，全部设置 `virtual={false}`；选项值仍使用原请求中的字符串，版本值不会变成数字。
- 审计、任务列表使用 `Table`，关闭内部分页；薄适配 `Pagination` 保留固定业务页大小、总数和请求期间禁用逻辑。
- 薄适配 `Modal` 只传递业务标题、宽度和写操作锁定。焦点、Escape、遮罩和退出动画交由组件库，写操作进行中不能关闭弹层。
- 操作反馈、读取错误、空结果和加载状态分别使用 `Alert`、`Empty`、`Spin`；失败不会伪装成空数据，也不会自动重放写操作。
- 图片、音视频、纯文本预览、受鉴权保护的头像读取与资源卡片布局属于业务 UI，保留取消读取、衍生图、Range 上限、对象 URL 释放及内容尺寸约束。
