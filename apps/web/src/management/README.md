# 后台与个人资源工作台

本模块管理 Canvas 的资源、任务、审计和服务状态。身份、分组、模型权限及费用由 New API 管理，不提供注册、密码、钱包、报价或账单页面。

- `/resources`、`/runs` 的浏览只读取当前用户资源和任务；`/admin` 下的资源、任务、审计和系统状态使用服务端管理员授权。
- 资源详情归属通过 `/v1/admin/resource-owners/:id` 读取。不能用用户传入的 ownerId 代替权限验证。
- 查询键包含当前登录用户和目标范围。切换身份重挂载页面，旧身份的迟到结果不进入新会话。
- 打开详情与轮询不自动重试生成；失败不会伪装为空结果，也不自动重放写操作。
- 原视频任务失败或历史已取消时，仅服务端确认可取回的详情显示「查询并获取视频」。用户显式点击后查询、下载和归档原任务，不重新创建生成请求。202 只表示受理；详情按 ID 独立轮询，资源归档后刷新任务及资源缓存，管理员获取的结果仍归原任务用户。
- UI 使用共享 `@multimodal-canvas/ui` 和 Ant Design。保留表单语义、危险操作确认、媒体尺寸约束及对象 URL 释放。
- 前端不存储 New API Key、PAT 或长期访问令牌；隐藏导航不能代替逐请求授权。

当前架构与部署见根目录 README。历史迁移和验收数字可从 Git 查阅，不能充当本轮验证。
