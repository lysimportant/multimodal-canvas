# 首页演示素材

首页使用独立的「自然观察」合成演示项目，不读取用户账户、项目、资源，不调用生成 Provider。

- `field-study.mp4`：来自 [MDN interactive-examples](https://github.com/mdn/interactive-examples/blob/main/live-examples/media/flower.mp4) 的公开示例，原名 `flower.mp4`。该仓库使用 [CC0 1.0](https://github.com/mdn/interactive-examples/blob/main/LICENSE)，于 2026-09-06 核实并获取。原始下载地址：https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4 。
- `field-study-poster.jpg`：从上述视频第 0.2 秒导出的完整视频帧，用作参考图、视频 poster 及同一示例素材的资源缩略图，没有额外版权限制。
- 这些文件是公开参考素材，页面明确标注为演示内容，不代表应用或任一模型已经生成了这些结果。无自动有声播放；视频由用户点击后播放，离开视口或进入后台时暂停。

原始视频及导出图片的尺寸、体积、哈希与验证记录见 `docs/homepage-ui-motion-todo.md`。
