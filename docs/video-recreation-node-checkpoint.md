# 短视频复刻专属节点

## 目标与范围

P1；本地验收日期为 2026-10-04。把整条短视频分析、动作与镜头模板、人物绑定、可选商品替换及现有视频生成入口集中到一个专属视频节点。人物是必需绑定，商品默认保留。分析和生成分别明确点击，不自动付费生成。

本任务不做片段选择或复杂剪辑器，不增加依赖，不修改工具包资料或 Codex Skill，不部署生产；PC Web 优先。节点尺寸不受分析摘要或提示词内容影响，只允许用户拖拽调整。

## 使用流程

1. 点击画布底部常驻的场记板图标「短视频复刻」，查看使用流程，选择「参考视频节点」后点击「创建复刻节点」。没有原视频时先点击「上传原视频」，上传到画布后重新打开此入口选择。也可在已有视频的悬浮工具栏点击「复刻短视频」。原节点不变，右侧创建带常驻场记板图标和「短视频复刻」标识的新视频节点。
2. 点击新节点的「尚未生成」区域，打开专属编辑区。顶部提供步骤概览和可展开的「使用流程」。点击「分析整条视频」，使用当前项目的默认分析模型，也可明确选择；此步骤需要模型真实支持视频输入。
3. 确认整体摘要、完整时长、镜头动作与未知证据，按识别出的角色选择或上传人物图片。单人视频只需绑定一张人物图；多人视频需逐角色确认，也可明确复用同一人物图片。
4. 默认不换商品。需要替换时选择商品图片，并填写已确认的用途与卖点；系统不会仅凭图片猜测功效。
5. 系统自动组装包含原视频、人物图片和可选商品图片的版本化引用及生成提示词。无需手写动作提示词，也可在原编辑区调整文本。使用原「生成」按钮明确提交，生成模型须支持参考视频、人物图片及完整时长。
6. 同一模板换人物或商品仅本地重组，不重复调用分析模型。「采用已有分析」仅保存已有结果；需要按新模型重新分析时明确点击分析按钮，两种动作不会混用。保存后可恢复；高度较小的浮层可以滚动，也可点击「打开完整编辑器」。

## 请求与资源约束

- 不要求选择片段，不默认改为 5 秒。完整时长或输入类型不受当前模型支持时阻断，不偷偷截短或加速。当前视频适配器只发送正整数秒数，因此非整秒分析可保存，但生成会明确拒绝，不取整或省略时长。
- 来源视频、人物和商品均冻结到明确的资源版本，未知版本不猜为 1。历史回显读取相应历史版本的时长，不套用最新版本元数据。
- 分析通过现有反推接口的可选 `purpose=video_recreation` 隔离；普通反推保持原有默认用途和幂等规则。响应补齐冻结的 `credentialId` 标识，使前端可核对精确分组模型，不返回密钥、凭据版本或内部授权快照。
- 首次分析和手动确认未知请求都先等待画布保存成功，再发送带稳定幂等键的 POST。网络结果未知时保留原键、模型和凭据身份；已有 runId 的恢复只 GET 原任务。已返回结果若保存失败，只恢复保存，不重新调用模型。
- 模板要求角色 ID 唯一、镜头时间轴从零连续覆盖全片、观察动作与镜头描述分离。不能观察到的细节保持未知，模型输出不视为原始提示词还原。
- 生成前前后端均检查绑定和时长；API还核对成功分析 Run 的项目、来源版本、用途和原始模板，以及最终提示词中关键资源引用的身份，不能用普通反推或手工伪造模板绕过。来源版本存在服务端探测时长时也独立对照（容差 0.1 秒），不信任客户端自行填写的时长；缺少探测值时仍依赖已成功分析中的观察时长，不能独立证明全片覆盖。
- 原视频只作为动作、时序、镜头及场景参考，人物外观来自绑定图片；商品替换时要求适配使用动作，不继承无依据的广告功效。文字指令不能保证模型严格复现每帧动作、脸部或包装文字。
