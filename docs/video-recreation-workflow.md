# 短视频复刻：对象识别与逐项替换

## 目标与验收

P1 跨模块功能。用户选择完整视频及分析模型，得到人物、广告商品的识别卡，再逐项保留或选择替换图片。视频生成模型独立选择，用户检查提示词后明确生成。换素材、阅读流程和恢复会话不能触发新的模型任务。

卡片展示可确认的外观描述、出现时间及原视频帧；只有分析提供可信区域时才裁剪。预览是原视频截图，不承诺透明抠图或自动候选素材生成。未知信息、无法解码和旧分析缺少定位时明确说明。PC Web 优先，不在本次增加移动端流程。

## 兼容与回退

保留配置 `version: 1`，新增可选识别元数据、保留人物列表、逐商品绑定及分析模型身份。旧角色绑定和单商品字段完整保留，不迁移数据库、不删除素材。旧商品引用不能静默套用到新识别商品，用户须明确清除旧绑定后逐项选择。资源和分析始终使用冻结版本，原 Run / 幂等键恢复规则不变。

回退源码不会撤销已保存的新配置。回退前备份画布 JSON；旧程序可能忽略新增字段，因此包含逐项保留或多商品替换的新画布不能用旧界面保存后再恢复。无需数据库迁移、对象存储清理或外部配置覆盖。

## 证据边界

本地 Mock 可以验证传输字段、保存恢复、明确提交与浏览器截图。浏览器使用仓库花卉视频及合成人物、商品分析，画面与标签不一致，因此只证明实际解码和交互，不证明识别准确率。`qwen3.8-omni-flash` 保留精确模型 ID，不在本任务发起真实付费请求；New API / 上游是否接受整条视频和识别合同尚未实测。R2、Neon 和生产环境不作为测试夹具。
