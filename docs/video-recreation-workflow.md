# 短视频复刻：对象识别与逐项替换

## 目标与验收

P1 跨模块功能。点击工具栏立即创建空复刻节点，不先弹来源选择窗口；首次点击节点聚焦并可拖动，再次点击同一节点才打开约四分之三视口、居中的三栏 Dialog。用户在左栏绑定完整视频及分析模型，得到人物、广告商品的识别卡，再于中栏逐项保留或选择替换图片。右栏独立选择视频生成模型，检查提示词后明确生成。换素材、浏览分析和恢复会话不能触发新的模型任务。

卡片展示可确认的外观描述、出现时间及原视频帧；只有分析提供可信区域时才裁剪。预览是原视频截图，不承诺透明抠图或自动候选素材生成。未知信息、无法解码和旧分析缺少定位时明确说明。PC Web 优先，不在本次增加移动端流程。

## 兼容与回退

保留配置 `version: 1`，新增可选识别元数据、保留人物列表、逐商品绑定及分析模型身份。空节点仅使用 `videoRecreationDraft: true` 标记，来源绑定成功后删除标记并保存完整配置；草稿不能提交生成。旧角色绑定和单商品字段完整保留，不迁移数据库、不删除素材。旧商品引用不能静默套用到新识别商品，用户须明确清除旧绑定后逐项选择。资源和分析始终使用冻结版本，原 Run / 幂等键恢复规则不变。

回退源码不会撤销已保存的新配置。回退前备份画布 JSON；旧程序可能忽略新增字段及草稿标记，因此包含空复刻草稿、逐项保留或多商品替换的新画布不能用旧界面保存后再恢复。无需数据库迁移、对象存储清理或外部配置覆盖。

来源与输出时长分开保存：分析始终覆盖完整冻结来源，生成秒数默认取分析结果，之后由用户修改。清晰度和比例从同一冻结版本的元数据或实际播放器尺寸补齐，不套用资源最新版本；已有参数及别名继续保留。API 不再要求输出时长等于来源时长，身份、所有权、全片分析、冻结引用和全能参考模式校验继续生效。回退到旧 API 后，不同时长的生成请求会重新被拒绝；回退前保留画布备份，按旧规则显式调整输出秒数，不改写来源或分析。

## 当前交互与任务记录

左栏将来源、时长、文件名放在「分析视频」标题行，视频下方直接显示模型选择与分析动作，摘要 Tab 不重复展示模型和完整时长。中栏场景及每个识别人物或商品分别横排；对象单项最高 130px，名称、原视频缩略图、资源选择、搜索与上传保持可见，商品说明在单项内部滚动。右栏的视频生成模型与视频参数入口同排居中；清晰度、生成时长、比例收进可悬停或点击的视频参数浮卡，未主动选择时不改写保存值；Skill 与生成按钮相邻。分析完成后立即显示生成提示词；未完成选择的草稿保留明确占位，不能绕过生成预检。普通视频新节点默认全能参考，已有节点的明确模式仍保留。绑定来源后，节点先回显冻结的分析视频，新产物成功归档后改为回显新产物。

复刻自动提示词只引用分析文字及明确绑定的图片，不自动加入分析视频；API 拒绝将同一分析来源通过额外提及或连线作为生成输入。其它由用户显式添加的引用遵循既有检查。新提交时仅识别并移除旧版自动生成且完全匹配的来源 token；已冻结 Run、保存画布及用户自定义提示词不改写。API 仍按精确来源版本、归属、视频类型、完整时长和分析 Run 校验。没有识别出可替换对象时，只要分析与用户提示词有效，不以对象数量阻止生成；其它引用和授权检查继续生效。

视频平台任务 ID 在获得后持久化并按授权在任务详情显示，个人任务详情按需读取真实发送的提示词及冻结资源名称、ID、版本。视频任务默认持续查询到终态，单次 HTTP 超时仍保留；已知平台任务 ID 的查询失败不会重发创建 POST。历史失败或取消且可恢复的视频在任务详情使用「查询并获取视频」只读取回。同步文字、图片、音频没有统一的平台任务 ID，提交超时后不能安全推断上游结果或自动重发。
