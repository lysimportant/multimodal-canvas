# 仙妖同款裙装

新增内置 Skill `xianxia-dress-character`（1.0.0），位于「人物与场景」。保留原「生成人物」；这里专门处理成年东方奇幻女性的同款裙装衍生，不把仙侠审美强加给其它人物任务。英文执行指令维护在 `packages/domain/src/prompt-skills.ts`，本文说明设计与用法，不维护第二份执行指令。

## 推荐的设计逻辑

**同系列固定裁剪结构，不固定角色、颜色与题材。** 用户给的两张图可提炼出贴体收腰、较短前层／开衩、长后摆、层叠外纱与飘动配件等共同视觉特征，但不能据此断言两件衣服的纸样完全相同，未露出的背部结构也未知。本 Skill 将这些共同特征整理成可复用的推荐裙型，而不是复制截图角色。

原草案把仙子绑定抹胸长裙、妖女绑定露腹舞衣，换身份就容易换整套服装。改为先确定一件母版裙装，之后只变妆造、配色、纹样和相容材质。同款系列内锁定以下结构；用户要求另一个系列或明确改变款式时，可重新确定母版：

| 固定结构     | 默认方向与边界                                                                             |
| ------------ | ------------------------------------------------------------------------------------------ |
| 上身与肩部   | 贴体收腰，抹胸／露肩／无袖中选择一种；同批保持领口和肩部连接方式，不强制露腹               |
| 腰线         | 固定腰线位置及衣身连接，不在仙子／妖女间自动切换软腰带与硬质腰封                           |
| 前裙与开衩   | 不透视的交叠前裙片，前层相对较短，侧开衩；同批保持侧别、高度及覆盖关系，不退化成泳衣加飘带 |
| 后摆与外纱   | 保持后长前短的长裙轮廓，轻薄外纱层叠拖尾；固定层数关系和拖尾比例，动态只改变飘动形态       |
| 披帛／独立袖 | 可选，但母版选定后保持连接位置；不因角色气质自动增删                                       |
| 材质覆盖     | 身体覆盖层不透视，透明感只用于外纱和配件；动作时保留合理遮挡                               |

## 开放衍生，而不是换色皮肤

变量库只是启发，不是封闭菜单。每个新主题从一个明确的视觉来源推导纹样、边饰和首饰，不把所有元素同时堆在衣服上。

| 维度       | 可继续扩展的方向                                                                           |
| ---------- | ------------------------------------------------------------------------------------------ |
| 灵感来源   | 植物生长、矿物裂理、天象、潮汐、昆虫翅脉、器物工艺、用户自创世界观                         |
| 配色       | 主色＋辅色＋少量强调色；可做同色深浅、冷暖对比、局部渐变，不规定仙子只能白、妖女只能红黑   |
| 纹样组织   | 沿前裙片走向分布、腰部聚拢、裙缘疏密渐变、局部暗纹，保留裁剪线的可读性                     |
| 相容材质   | 哑光绢、缎面、轻纱、珠光薄层、细金属绣线；不为了换材质把柔软拖尾变成整套硬甲               |
| 人物妆造   | 成年人物的不同脸型、肤色、发式、发饰、眼妆和性格；同一个角色保留身份，不同角色不共用一张脸 |
| 气质       | 清冷、明朗、慵懒、狡黠、威严、野性、幽异，可交叉组合，不以露肤多少区分仙妖                 |
| 场景与动作 | 与主题一致的单一环境、可实现姿态和风向；武器、伞、面纱、赤足都不是必选                     |

例如「月白冰裂青瓷」「墨绿铜锈蕨纹」「暖赭流沙金线」「苍蓝海月水纹」可以来自同一裁剪结构，但纹样组织、面料反光、发饰和人物情绪应同时有区别，不只是改裙子颜色。

## 在项目中使用

在节点的「Skill 配置」中选择「人物与场景 → 仙妖同款裙装」，输入人物和主题要求，再通过现有文字模型优化流程生成预览。只有显式采用才更改提示词；本 Skill 不自行调用绘图接口。

可直接输入：

> 给我一位成年墨绿铜金蕨纹妖女，神秘但不阴森。贴体收腰、侧开衩、层叠外纱长后摆，长裙轮廓清晰，不要面罩。全身，东方幻想角色概念设计。

同款多角色：

> 设计四位成年仙子／妖女，沿用同一件裙装的领口、腰线、前裙片、开衩侧别、后摆比例和披帛连接。四个主题分别是冰裂青瓷、铜锈蕨叶、日蚀金环、雨后苔石；人物、发型、纹样和材质气质要有区别，不能只换色。输出四段能独立使用的中文绘图提示词，不要拼成多人画面。

换母版但保留衍生能力：

> 将这组的母版改成单肩领口、左侧开衩，保留交叠前裙和两层纱质长拖尾。接下来衍生的仙子和妖女都用这套新母版，不改变各自身份。

## 两个同款示例

下面是人工整理的使用示例，不是真实绘图结果。两段刻意重复结构，便于单独复制；具体模型仍可能出现结构漂移。

### 月白青瓷仙子

> 一位成年东方奇幻女性，神情宁静而疏离，乌发低挽，配青瓷质感细簪。身穿露肩贴体收腰长裙，腰线位于自然腰，不透视的交叠前裙片覆盖腿根，较短前层与右侧开衩形成不对称轮廓，两层轻纱从后腰延展成长后摆，披帛固定于两侧上臂。裙身月白，内层灰青，腰侧与裙缘以银灰细线表现疏密有序的冰裂纹；绢面柔和反光，外层薄纱轻透但衣身不透视。人物静立雨后的青石庭院，微风让披帛与后摆向同一侧舒展。平视全身构图，前裙、侧衩和长后摆均可辨认，柔和阴天光突出面料层次，东方幻想角色概念设计，不含字幕和水印。

### 墨绿蕨纹妖女

> 一位成年东方奇幻女性，神情狡黠而从容，深棕长发半束，配铜色卷叶发饰。身穿露肩贴体收腰长裙，腰线位于自然腰，不透视的交叠前裙片覆盖腿根，较短前层与右侧开衩形成不对称轮廓，两层轻纱从后腰延展成长后摆，披帛固定于两侧上臂。裙身墨绿，内层灰金，以少量旧铜色细线从腰侧向裙缘展开蕨叶脉络；缎面光泽集中在转折处，外层薄纱染有很淡的苔绿色，衣身不透视。人物侧身回眸立于雨林古阶，微风让披帛与后摆向同一侧舒展。平视全身构图，前裙、侧衩和长后摆均可辨认，林间侧光勾勒裙缘，东方幻想角色概念设计，不自动添加面罩、角或尾巴，不含字幕和水印。

## 适用边界

- 这是一条应用内提示词优化规则，不是强制扩展所有人物任务的全局 Codex Skill，也不是三维服装纸样。
- 本轮验收基线的优化器只收到参考标签和资源占位标记，不读取图片像素；实际看到的结构需由用户说明或来自已确认的视觉描述。占位标记保持原顺序且只出现一次，不凭图片名称编造细节。
- 默认输出一段原输入语言的提示词；只有明确要求时才输出英文、双语或多款。内部规则使用英文，沿用项目现有合同，不私改全局输出语言。
- 不无条件附加 `--ar`、权重语法或新 JSON 字段；仅在用户指定工具及其已确认语法时适配。不要用「8K」或互相冲突的引擎标签代替服装描述。
- 同款文字描述提高设计约束的清晰度，不保证不同模型或多次生成的像素级一致。真实效果验收需要用户授权模型和费用，本次未发起收费绘图请求。
