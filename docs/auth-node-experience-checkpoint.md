## 兼容性与恢复

新增公开找回密码申请接口，原有验证接口保持兼容。复用现有存储，无数据结构迁移；本机模型偏好使用独立版本化 key，不改写旧画布。默认参数只在新建或明确切换模型时补齐缺失值，已有参数保留；无模型契约的自由输入字段不猜测值。

正常申请对未知、待验证、禁用账户返回相同通用结果；邮件服务未配置或投递失败明确返回 503，保存脱敏投递失败记录。错误状态和请求耗时尚未做完全不可区分处理，不能宣称完全防止邮箱枚举。真实 SMTP 收件箱投递未验收。原有约 1 MB 主 JS 分块警告保留，没有扩大到打包优化。
