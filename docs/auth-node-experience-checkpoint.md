# 登录与节点参数体验

Canvas 使用 New API 唯一登录。旧密码、邮箱验证码、找回密码和管理员初始化表单已退出；密码与账号资料在 New API 管理。Canvas 保留可撤销 HttpOnly 会话、退出、跨账号缓存隔离和内部资源 UUID。

节点提示词保留清晰的输入用途和无多余聚焦边框的编辑体验。模型偏好按用户、媒体类型和节点模式保存，读取时核对当前分组目录。参数保持三列自适应和向上展开；新建或明确换模型时才补齐缺省枚举值，已有参数不被覆盖，无合同字段不猜值。

当前流程与证据见[账号接入计划](newapi-account-integration-plan.md)和[实施检查点](newapi-account-implementation-checkpoint.md)。旧密码恢复与 SMTP 验收不再是 Canvas 运行前提。回退必须兼容已迁移的身份和执行授权，不能仅回退界面后恢复旧登录。
