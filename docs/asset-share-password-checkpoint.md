# 分享密码与大肥鱼头像检查点

更新时间：2026-10-06。任务级别：P1；基线 `main @ 840c40e`，开始时工作区干净，上游 `origin/main`。Node `v24.12.0`、pnpm `11.19.0`，本地依赖齐全。

## 目标与验收

- `/share` 页头使用已有彩色大肥鱼头像，解锁页和资源页保持相同品牌。
- 预览 Dialog 分享按钮旁提供可选查看密码，默认留空。输入本身不创建分享；点击分享时才发送密码，复制的链接不包含密码。
- 受保护分享必须先解锁才可读取资源名称、预览和原文件；元信息、GET/HEAD 内容及 Range 读取遵守相同校验。
- 无密码链接和原有图片缩放、音视频播放、固定资源版本保持兼容；不改变画布节点尺寸。

不涉及生产部署、数据库迁移、依赖更新、供应商调用或旧链接撤销。当前为无持久分享表的方案，修改密码后重新生成链接不会改变旧链接。

## 接口与兼容边界

- 创建接口沿用 `POST /v1/assets/:assetId/share`，新增可选 `password`。省略或空字符串保持无密码；非空密码最长 128 个 UTF-16 代码单元，空格保留。
- 无密码分享使用原 v1 不透明令牌；带密码使用 v2，将随机盐及 scrypt 校验值放入 AES-GCM 加密载荷。服务端不保存明文密码。
- 未解锁的元信息和内容接口返回 `401 SHARE_PASSWORD_REQUIRED`，不返回资源信息。
- 匿名解锁使用 `POST /v1/asset-shares/unlock`，请求为 `{ token, password }`，正确后返回 `{ accessToken, expiresAt }`。错误密码返回 `401 SHARE_PASSWORD_INVALID`，失效链接返回 404。解锁单独限制每 IP 每 15 分钟最多 10 次。
- 临时访问凭据与原分享令牌绑定，用途隔离，最多有效 1 小时且不超过原链接到期时间。读取请求通过 `access_token` 传递；元信息中的内容 URL 携带同一凭据。访问凭据仍属于应保密的短期访问权，不能承诺已解锁接收者无法保存或转发内容。
- 密码与凭据不写入浏览器存储；页面刷新后重新输入密码。到期后卸载媒体并重新验证，链接仍有效时可再次解锁。
- 填写密码后若 API 返回旧版 v1，前端明确拒绝复制或报告创建成功。密码框编辑不会被浮层展开动画或关闭后的焦点恢复打断。
- 内存限流桶按各自窗口清理，普通读取不会提前重置十五分钟解锁计数；Redis 原有独立 TTL 保持不变。
- 分享页首响应保持通用 SEO/noindex 信息，不输出资源名称、密码或令牌。现有查询串及访问凭据日志脱敏继续适用。

无需备份迁移或修改既有资源数据。Web/API 应一起更新；回滚到旧 API 时旧代码拒绝 v2，不能把受保护分享降级为无密码。既有 v1 分享继续兼容。
