## 接口与回滚边界

- 新增 `GET /v1/assets/:assetId/versions/:version/derivatives/thumbnail`：仅应用会话可读；不扩展原 `access-url` 签名权限。`GET /v1/assets/:assetId/derivatives/thumbnail` 的会话入口支持旧资源按需生成，原签名入口合同不变。
- 缩略图响应包括 ETag，可选 X-Original-Width / X-Original-Height。不存在或越权404；非图片415；源变更409；暂时繁忙503并给 Retry-After。Web只对明确thumbnail_busy做有界退避，不重发任何生成供应商请求。
- 原文件的content/version/content接口不变。索引包含latestVersion时，展示图、Dialog和下载统一定位到该版本，防止缩略图是v2而下载拿到稍后生成的v3。
