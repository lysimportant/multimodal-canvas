## 当前接口行为

图片生成节点没有图片输入时发送 `/v1/images/generations`；有图片输入时发送 multipart `/v1/images/edits`。图片来源可以是原图连线，也可以是提示词中的图片资源引用。提示词引用保留资产 ID 和冻结版本，Worker 按该版本读取，Provider 将实际图片文件写入单图 `image` 或多图重复 `image[]` 字段。

本地内存运行模式同样在执行前读取冻结图片，使用项目与用户作用域重新检查资产权限和版本；不会获取任意外部 URL。取消、归档或版本不可用时停止发送。前端缓存图片已解码时直接结束加载状态，避免引用缩略图被加载遮罩长期覆盖。

模型目录中的 `mentionMediaTypes` 及其别名只描述目录信息；缺省、仅声明文字或空列表都不阻止图片引用，也不据此判定供应商真实能力。`imageEdit` 的明确禁用、格式/参数/数量限制，以及资源提及的模式、角色、数量和混合限制仍校验。尚未接通的媒体输入按实际适配边界拒绝，不能把引用当作纯文字丢弃。

相同资产同一版本重复引用只上传一次；不同资产或不同版本仍是不同输入。GPT Image 模型族默认最多 16 张，其它别名默认 1 张，目录可通过 `imageEdit.maxImages` 声明上限且不超过 16；超出时明确失败。不能确定旧连线版本时，不猜测它与资源提及是同一版本。

供应商返回的拒绝或网络错误沿现有错误链路展示，不增加自动重发或回退文生图。源文件的内容不会写入持久化任务或请求说明，只保存来源身份和最终提示词。

## 已有生成图片的连线输入（2026-09-29）

图片或视频目标通过内容、原图、参考图、首帧或尾帧端口连接到生成图片时，提交边界优先读取同项目、同来源节点最近一次成功归档结果，并冻结其资产和版本。仅本次执行快照把该图片当作 source，截断其上游生成链；保存的画布、节点类型与连线不变。显式图生图原图仍按原身份冻结，手动覆盖不被历史结果替换。

来源没有成功回显时保留原 DAG；明确运行来源节点本身仍会执行其生成配置。已有结果缺版本、资产已归档、版本失效或无权访问时在入队前拒绝，不退回重新生成上游。该行为不会自动修正文字节点上误选的图片模型。

连线资源卡片改名同时更新对应正文的结构化提及，按资产、版本和权威旧别名定位；同资产的自定义别名、其它版本及普通旧称不被批量替换。已保存但缺少版本的旧别名可按来源确知版本只读投影，只有明确编辑才持久化，直接提交则把规范化文档放入新 Run。无法确定版本或名称有歧义时明确提示，不借资源目录最新版猜测。

供应商明确拒绝创建时，Worker 保留脱敏原错并结束该次队列重试；同 Run 人工重投和进程重启也不再次 POST。持久任务按数据库主键恢复上游节点的本地身份，不把它混同为根任务。已有回执、归档和平台任务仍优先恢复；送达不明时继续禁止重复创建。

历史 Run 不回填，历史 retry 继续使用原冻结快照。使用修复后的连线输入需在目标节点输入面板明确点击“生成”新建任务，不能靠重放原错误请求改变历史快照。当前修复没有发起真实供应商调用；证据与交付状态见 [连线修复检查点](connected-node-reference-checkpoint.md)。本节改动无数据迁移，回滚仅替换应用镜像；原任务和资产数据必须保留。
