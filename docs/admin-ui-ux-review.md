## UI TODO：视觉与布局，16 项

- [ ] **UI-01 / P0 账户入口一致性**：主页、工作台、画布和后台都以头像表示账户；退出使用清晰文字及 Lucide 退出图标，hover/focus 提示与动作一致。
- [ ] **UI-02 / P1 后台结构**：PC 使用稳定侧栏和工作区，后台首页直接展示可操作内容；紧凑表格/列表优先，页区不做嵌套浮动卡片。
- [ ] **UI-03 / P1 导航位置感**：当前菜单、页标题、面包屑与用户范围一致；深链进入用户资源详情仍能辨识所属用户及返回路径。
- [ ] **UI-04 / P1 用户分组辨识**：全站资源入口清楚显示用户头像/名称、资源数和占用；资源详情持续显示所有者，不仅靠颜色区分用户。
- [ ] **UI-05 / P1 表格可扫描性**：用户表格对齐名称、邮箱、状态、更新时间和操作列；长邮箱不压缩操作按钮，排序和分页不改变列宽。
- [ ] **UI-06 / P1 资源预览稳定性**：图片/视频使用稳定宽高比，音频有固定播放器区域，文本有受限预览；媒体加载、错误和长内容不撑大网格或画布节点。
- [ ] **UI-07 / P1 字号和层级**：后台标题与紧凑面板匹配，不使用宣传页大标题；正文、辅助信息及字段标签保持可读，字距为 0，不按视口连续缩放字号。
- [ ] **UI-08 / P1 主题和状态色**：复用现有主题变量，校验亮/暗/高对比主题；成功、警告、失败有文字/图标，不能只靠颜色，避免全页单一色系。
- [ ] **UI-09 / P1 表单一致性**：个人信息、邀请、验证、改密表单统一标签、必填标识、帮助/错误区与按钮排列；错误出现不遮挡输入和提交区。
- [ ] **UI-10 / P1 图标与控件**：命令使用图标或图标加文本，选项使用菜单/分段控件，二元项用开关；图标按钮有可访问名称与 tooltip，命中区域稳定。
- [ ] **UI-11 / P1 弹层层级**：统一菜单、侧栏、详情面板、模态框和通知层级；弹层不被导航挡住、不越界，避免把画布属性区整体错误搬进新弹层。
- [ ] **UI-12 / P1 加载与空态**：用户列表、资源网格和预览分别使用匹配尺寸的占位；区分无内容、无搜索结果、无权限、加载失败，文案只服务当前业务。
- [ ] **UI-13 / P1 侧栏完整动画**：开/关均有平移和透明度变化，建议 160-220ms；遮罩同步退出，动画结束后卸载，快速反向切换无闪烁。
- [ ] **UI-14 / P1 页面出入动画**：建议 120-180ms 淡入/淡出配合不超过 8px 位移；固定导航不重复跳动，旧页退出期间不可误点旧控件，减少动态效果时即时切换。
- [ ] **UI-15 / P1 桌面尺寸验收**：在 1280x720、1440x900、1920x1080 及 200% 缩放下检查文字、表格、工具栏与模态框；允许有意的表格滚动，不允许全页意外溢出。
- [ ] **UI-16 / P2 基础窄屏与媒体退化**：390px 宽先保证登录、验证、个人资料、返回导航可用；图片损坏、视频不支持、头像缺失有稳定替代，复杂手机画布后置。

## UX TODO：流程与反馈，16 项

- [ ] **UX-01 / P0 头像无副作用**：打开/关闭账户菜单、查看资料和切换页面不注销、不清画布、不重新提交运行；只有明确退出才撤销会话。
- [ ] **UX-02 / P0 登录后续接**：真实失效后说明状态并保留安全的用户草稿和目标地址；返回原操作位置，由用户确认重试写入，防止重复项目/收费任务。
- [ ] **UX-03 / P0 临时故障恢复**：区分网络失败、权限不足、会话过期与服务端错误；普通业务请求网络抖动保留会话，恢复后连接已有任务；主动退出按独立策略处理，不把错误一律变成登录弹窗。
- [ ] **UX-04 / P1 初始化引导闭环**：首次进入未初始化的 `/admin` 直接显示管理员配置页；完成后持久化标记，后续访问、换浏览器、清缓存和重启均只走登录/后台；失败允许继续，并发提交只成功一次。
- [ ] **UX-05 / P1 邀请状态明确**：管理员创建用户后能区分“等待发信”“已发送待验证”“失败”；允许重发与取消有效邀请，失败不丢录入内容。
- [ ] **UX-06 / P1 验证异常可处理**：错误码、过期、重发限制、链接重复使用、邮箱冲突有具体反馈；返回表单和重新获取验证都能继续，密码与验证码不持久化为草稿。
- [ ] **UX-07 / P1 修改资料可恢复**：保存中禁重复提交，成功反馈对应真实持久化；失败保留字段值和焦点，离开未保存表单有合理处理。
- [ ] **UX-08 / P1 修改密码可理解**：显示新密码规则和确认字段，支持密码管理器与显隐；说明完成后的会话结果，错误绑定到正确字段。
- [ ] **UX-09 / P1 用户切换不串内容**：管理员切换用户时同时切换查询作用域、统计、面包屑、选择集和分页；不能短暂显示上一用户资源或误对上一用户操作。
- [ ] **UX-10 / P1 查找与返回连续性**：资源搜索、类型/来源筛选、排序及用户组可恢复；从详情/预览/画布返回保持合理滚动位置，不保留已失效权限的数据。
- [ ] **UX-11 / P1 上传与生成统一收录**：上传完成和生成归档成功后自动进入正确用户资源库；处理中、失败与可重试状态可见，文本及派生资源不遗漏。
- [ ] **UX-12 / P1 长任务可离开**：离开画布、进后台、打开账户页面不取消后台任务；返回后显示最新状态及已有结果，不创建重复任务。
- [ ] **UX-13 / P1 批量与危险操作可审查**：显式展示对象、所属用户、数量、引用影响和逐项失败；归档可恢复，永久删除/覆盖单独确认。
- [ ] **UX-14 / P1 键盘与读屏闭环**：Tab/方向键/Escape 操作菜单，模态框焦点受控且关闭后归位；新页面焦点合理，中文输入法组合输入不误提交。
- [ ] **UX-15 / P1 退出和换号完整性**：退出或切换账户后关闭旧事件流、撤销可撤销 URL、隔离旧缓存/草稿/选择；浏览器后退不能重新露出旧账户内容。
- [ ] **UX-16 / P1 管理行为可追溯**：每次资料、用户状态、资源归属与配置变更都有结果和审计入口；错误可提供脱敏请求编号，不能显示伪成功。
