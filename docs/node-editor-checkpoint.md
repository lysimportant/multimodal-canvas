# 节点编辑器与超时交付检查点

更新时间：2026-09-10。起点 `main @ 3c11226`，原始工作区干净，Node `v24.12.0`、pnpm `11.19.0`，使用已有项目依赖。

## 本次目标与实现

- 新建节点默认 `230 × 216`，比原来的 `180 × 166` 宽高各增加 50；居中定位共用尺寸常量，保留已保存尺寸、手动缩放和预览内容裁剪。
- 图片、音频、视频编辑器将模型之外的参数收纳在点击展开的参数页中；模型与生成按钮之间的一个按钮展示两至三个当前参数。未配置参数显示默认/未设置，不自动写入猜测值。
- 放大按钮打开模态 Dialog，共享节点的提示词、模型和参数；顶部显示显式连线及 `@` 引用文件，资源暂时缺失时保留引用名称。关闭后回到原编辑器并恢复键盘焦点。
- 输入区、参数按钮、生成按钮共用主题中性色；明亮、深色及其他现有主题跟随工作区。参数页使用独立滚动区域，不撑大节点或快速编辑器。
- 默认节点请求超时提高到 15 分钟，管理员可在设置中自定义并持久化；API、Worker、视频轮询均读取对应设置，前端不再因固定轮询次数误报长任务超时。作用范围、部署覆盖与回滚见 [节点超时设置](node-timeout.md)。
