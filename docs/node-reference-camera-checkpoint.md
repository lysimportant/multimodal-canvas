## 使用方法

1. 点击任意文字、图片、音频或视频节点，提示词上方依次是上传、文件夹加号（添加参考资料）、相机（拍照引用）。完整编辑器沿用相同入口。
2. 添加参考资料后连续点击画布中要引用的资源，按 Esc 或「完成添加」退出。资料类型与生成模型是否接受是两件事，生成仍需现有能力校验。
3. 拍照引用会打开预览并请求摄像头权限；点击「拍照」后相机立即关闭，确认「使用照片」才上传并加入引用。可「重拍」或取消，保存失败保留原照片供重试。
4. 页面内检测非安全上下文时要求改用 HTTPS 或 localhost；权限拒绝、设备不存在/占用、预览或图片编码失败有明确错误。关闭保存中的窗口不会撤销已经发出的上传，但迟到结果不会引用到新节点。
5. 底部胶囊的短视频复刻只显示场记板图标，鼠标悬停或键盘聚焦可看到提示，点击仍打开原有使用流程。
