# 设置页布局与当前合同

设置页沿用现有主题、桌面侧栏和键盘可访问的分类导航。当前账号入口为 New API 唯一登录，设置展示本人分组准备状态、刷新、文字/图片/音频/视频模型默认值与请求超时；模型保留所属分组，不提供地址、Key、尾号、连接新增/激活/删除表单。

页面与画布弹窗共用 SettingsPanel。异步读取和刷新显示忙碌状态，成功组仍可用，失败组显示原因；旧账号的迟到响应不能回填新会话。普通模型设置与提示词 Skill 保留。

旧手动连接的设计、Lighthouse 数值和浏览器计数仅存在 Git 历史，不作为当前版本验收。当前工程和实际 PC 证据见[账号接入检查点](newapi-account-implementation-checkpoint.md)。复杂移动端扩展继续后置。
