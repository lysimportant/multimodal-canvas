## 本次实现

首页保留 `Multimodal Canvas` 产品名和工作台入口，使用全幅网格工作流场景、真实参考画面、克制的节点与连线。正文采用连续内容区，提供可播放的本地公开样片、资源条目和现有项目入口。颜色使用中性底色、青绿功能色、珊瑚强调与少量亮绿；支持现有明亮、深色和高对比主题。

首屏文字和场景在 500-700ms 内进入；内容区初次进入视口时轻量显示，始终保留首帧可见内容。连线由节点真实边界计算，缩放与尺寸变化后自动更新。鼠标周围为 26px 四角定位标记，保留系统指针；正文、选择文本、媒体控件、弹层、离开窗口或页面时退出。按钮与视频入口有独立边缘反馈和键盘焦点，外部尺寸稳定。

动效遵循 `prefers-reduced-motion`，可通过首页右上角图标关闭。触屏不启用指针追随；后台标签与离屏首屏停止装饰运动。指针移动用单次 RAF 合并写入，不创建持续 React 渲染循环。低性能设备、节省流量设置或五秒内三次不短于 120ms 的长任务会降级为静态。

首页不会读取私有项目、注销账户、创建项目或运行生成任务。演示视频只预加载元数据，不自动播放；原生播放器支持播放、暂停、进度、静音和全屏，离开视口或进入后台时暂停且不自动恢复。视频加载失败保留 poster 并允许明确重试，图片加载失败保留比例与可访问替代说明。

## 验证与性能记录

环境：Windows、本地 pnpm workspace，Node 与 pnpm 版本以主任务 `IMPLEMENTATION-CHECKPOINT.md` 基线为准。首页使用项目既有 React、lucide、Vitest 与 Playwright，没有新增依赖。独立开发服务器为 `http://127.0.0.1:5186/`，未修改生产容器。

- 原始基线：既有首页两项单测通过；原实现没有首页 animation/transition/鼠标监听，没有真实图片或视频文件。性能对照采用同一最终页面的静态与动态模式，不把旧版源码审计当作视觉或帧率测量。
- `pnpm --filter @multimodal-canvas/web exec vitest run src/pages/HomePage.test.tsx src/pages/HomeMotion.test.tsx`：2 个文件，8 项通过。
- `WEB_BASE_URL=http://127.0.0.1:5186 pnpm --filter @multimodal-canvas/web exec playwright test e2e/home-page.spec.ts`：7 项专项通过。前六类隔离验证使用真实首页组件；另有实际 App `/` 路由回归，避免把组件挂载误报为账户系统集成测试。Windows PowerShell 先设置 `$env:WEB_BASE_URL` 再运行 pnpm。
- `pnpm --filter @multimodal-canvas/web typecheck`：通过。
- `pnpm --filter @multimodal-canvas/web build`：通过；Vite 提示主 chunk 大于 500kB。该提示涉及整个应用，未为首页任务调整打包策略或拆分其他模块。
- 首页新增/修改源码、样式和专项测试的 `prettier --check`：通过。Markdown 按仓库 ignore 设置另行人工检查链接与状态，不谎称已被格式工具扫描。

性能预算：首屏 poster 小于 100KB、视频文件小于 1.5MB，浏览器可以为元数据读取部分视频；桌面 RAF p95 小于 60ms；十次卸载重挂后显式 GC 的 JS 堆增量小于 2MB；指针停止后没有持续 RAF 循环。三次不短于 120ms 的页面长任务触发静态退化，不等待所有媒体解码。

同机 1440 × 900、Chromium、每组 90 个帧间隔：静态与动态的中位数均约 16.7ms，p95 约 16.8ms，大于 50ms 的帧均为 0。十次卸载重挂后显式 GC 测得 JS 堆从 7,905,528 增至 8,618,520 字节，增量 712,992 字节；四倍 CPU 限速下指针移动、关闭动效和进入工作台约 702ms。数据用于本机回归，不宣称所有设备达到固定帧率，也不替代长期使用的内存分析。
