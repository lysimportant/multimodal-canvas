## 视觉方向与素材复用

建议把科技感落实为可读的工作流关系、精确的边界、清晰的媒体结果和有因果关系的动态反馈。首屏继续以 Multimodal Canvas 为标题，配合无遮挡的工作流场景和主要入口；正文减少 DAG、凭据版本等实现术语，保留能帮助用户理解产物、版本和来源的业务信息。

构图采用全幅或不加装饰边框的真实产品场景，文字直接叠放在预留的清晰区域；下一段内容在首屏底部保留可见线索。下方使用连续内容区和精简的产品演示，不把整个页面拆成大卡片。后台仍保持紧凑工作界面，此处的首页视觉不复制进管理表格。

配色先做静态对照稿，推荐清晰中性色背景、深色文字和少量青绿/珊瑚色功能强调；深主题保持相同层级和对比度。禁止用装饰性光球、渐变光团、bokeh、粒子海或全页紫蓝渐变代替产品内容；鼠标反馈不得变成模糊光斑。字体不随视口连续缩放，字距为 0。

## 鼠标周围与悬停目标的区别

**鼠标周围特效**跟随指针位置：建议一个细线环或四角定位标记，直径约 20-28px，位于原生指针周围；不隐藏系统光标，不带模糊光晕，不留下长拖尾。只在首页合适的演示区域启用，进入输入框、正文选区、原生媒体控件或弹窗时退出。装饰层必须 `pointer-events: none` 且对读屏隐藏。

**悬停元素边缘效果**跟随被指向的对象：按钮、可交互演示节点或媒体边框出现一段沿边缘移动的细线/角标；反馈始终约束在目标边界，不扩大其布局尺寸。键盘聚焦提供同等清晰的静态边界。仅可操作对象获得交互暗示，静态状态标签不伪装成按钮。

两种效果可搭配，但承担不同职责：前者提示指针与场景关系，后者明确实际操作目标。建议先完成目标边界和基础页面动画，再加入可关闭的指针周围效果；触屏不保留 hover 状态，减少动态效果或低性能条件下使用静态边界与 poster。
