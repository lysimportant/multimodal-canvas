## 当前行为

- `mentionMediaTypes`、`semanticRoles`、`maxMentions`、`supportsMixedMentions`、`modes` 均为可选限制。缺省不阻断；显式空数组、零上限、禁止混合媒体以及其他明确限制仍校验。视频引用转为参考输入前也检查明确限制。
- 文字节点的 `@` 资源沿已有聊天内容映射发送；图片连到 `content` 时发送真实 `image_url`。纯文本消息的内容、名称和顺序保持原行为。
- API 本地内存执行和 Worker 均读取冻结版本；本地支持文字 `@` 资源及文字/图片连线。校验项目和个人资源归属、归档、MIME、大小、版本、UTF-8 和取消状态，不抓取任意外部 URL。
- 图片生成仍根据原图输入选择 `generations` 或 `edits`，最多一张不同原图。Grok 1.5/1.5.1 的参考图仍沿已接通的视频接口发送。
- 当前 TTS 未接通资源提及；视频未映射的组合仍拒绝，并明确说明项目适配边界，不再把缺声明说成模型不支持。
- 不增加自动重发、静默丢弃媒体或降级为纯文本。供应商返回的模型或参数错误沿现有错误链路展示。

多资源读取时，后读资源完成前，先读资源可能已被归档。API 本地执行和 Worker 均在全部读取结束、请求说明持久化后复核资源权限和归档状态，只重查元数据，不重复下载文件。
