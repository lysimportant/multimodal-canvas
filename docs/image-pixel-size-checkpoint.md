## 兼容与回滚

`size` 是现有公开数据格式中的已支持字段，本轮不新增 schema 或迁移。旧尺寸别名仍可读取；新编辑只规范化当前节点，未知参数和原生质量保留。历史未知请求仍按原身份查询，不能因参数变化重新生成。

回滚使用本轮提交前的应用代码重新构建，不覆盖数据库、画布、Run 或素材。已有 `size` 参数在旧版本同样受支持，回滚不会要求将其改回 K 档。
