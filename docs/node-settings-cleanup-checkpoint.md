# 节点外观与设置合同

生成/转换节点保持固定外框尺寸，预览内容不得撑大节点；只有用户拖拽调整尺寸。悬停、选中或键盘焦点显示顶部名称、启停、状态、删除操作；手动 resize 显示控制点，来源节点继续使用既有卡片。

节点模型身份为本人分组凭据引用和精确模型名。模型失效时要求重新选择，不能自动切换组。旧手动 Key 删除、激活、历史文件存储等产品合同已退出；分组 Key 由 New API 授权同步，人工变更不会自动复活。

设置加载、保存与刷新继续显示忙碌状态并避免重复提交。当前认证、分组和 PC 验收见[实施检查点](newapi-account-implementation-checkpoint.md)；旧阶段测试数和端口不再作为当前运行证据。
