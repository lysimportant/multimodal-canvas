## 兼容性和回滚

无需 Prisma schema 迁移。数据库复用已有 `label=deleted` 标记，本地 JSON 凭据版本增加可选 `deleted` 布尔字段；旧文件缺省视为未删除。删除不物理清空历史密文，保证运行中的任务不会因设置变化中断。新请求、列表、刷新目录和重新激活均拒绝已删除版本。删除当前活动 Key 后不擅自切换其他连接，用户可手动选取其余 Key。

上线前按既有部署流程备份数据库、本地凭据 JSON 及对应加密材料，备份只留在受控存储。本轮未删除真实用户 Key，也未操作正式部署。回滚前端可保留新版凭据服务；旧后端不识别删除标记，不能在已产生新删除记录后直接降级，否则会重新显示旧 Key。若必须回滚后端，须先制定保留删除状态的数据恢复方案，不能通过删除历史密文解决。

浏览器验证使用 Mock API、合成 Key 和测试项目，不调用真实 Provider。预览沿用 Web `http://127.0.0.1:5173/`、API `http://127.0.0.1:3000/health`；测试端口 5193/5194/5195 与用户开发服务隔离。

Vite 仍有既有约 1 MB 主分块提示；正式部署与跨设备长期运行未验收。本次专用 PostgreSQL 隔离容器验收后停止，保留容器用于恢复；随机测试 schema 已由测试夹具清理。
