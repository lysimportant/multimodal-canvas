## 修复与兼容边界

- 文字连到文字、图片、视频或音频的提示词/内容端口时，优先冻结同项目同来源节点的成功 txt 结果及版本；没有归档结果时，直接使用当前非空正文（包括 Skill 回填），不将图片模型发往文字接口。
- 只改变新运行的执行快照，不改保存画布、来源模型、历史任务或计费记录。手动输出保持原优先级；空白来源保留 DAG 执行，明确单独运行文字节点仍需可用的文字模型。
- 尚未生成文字结果的资源提及不降级成文件名，需先得到文字结果；无权限、归档、缺版本均在发送前失败，不能回退重跑来源。
- 同步补 API 内存执行的 txt 水合：所有媒体目标读取冻结版本的 UTF-8 正文；Worker 原有水合路径不需要运行时代码改动。
- 对已填写的文字指令仍希望执行扩写时，先明确运行该文字节点，再让下游使用归档结果。不会隐式创建额外文字调用。
