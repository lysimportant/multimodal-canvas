# 柔光日系氛围插画

应用内 Skill：`soft-anime-atmosphere`，版本 `1.1.0`，分类「人物与场景」。输入少量人物、场景或动作词，经显式「优化」得到可供生图的完整提示词；不直接调用绘图服务。英文执行规则唯一来源为 [领域定义](../packages/domain/src/prompt-skills.ts)，工作台提供匹配版本的中文说明。

共用画法是细而浅的线条、柔和分层上色、细分发束与少量飞发、可读布料纹理、克制绘画／纸感，以及有空间层次的环境。日景可以明亮柔和，书房和雨夜仍保留深色环境；「柔光」不等于低反差、全画面泛白或统一高曝光。

这是**同一插画语言下的多种穿搭和场景**，不是同纸样衣服。与「仙妖同款裙装」并列存在：后者的交叠前裙片、开衩、长后摆结构不自动套入本 Skill；该仙侠 Skill 的名称、ID、版本、规则均不变。

### 1.1.0 的细化

- 奶油窗光是可选分支，不把每张图都处理成高曝光客厅。用可见的明度、冷暖、接触阴影与织纹区别浅色物体，不用泛白或全局模糊代替柔光。
- 衣服写清领口、腰线、收褶、袖口、织纹方向和厚度；可选浅桃裙与象牙色开衫，不强制所有穿搭出现蕾丝、薄纱或亮缎。
- 坐姿写清坐垫承托、手部接触与膝踝透视，保留脸部视觉焦点。抬腿、白袜、红眼、白发、猫耳和尾巴只在用户指定或明确参考角色时使用，不锁成固定角色。
- 不新增预设 ID，也不覆盖用户自定义副本。新版只影响后续优化；已有运行仍使用提交时冻结的指令快照。

## 你只需提供的内容

最简输入即可，例如：

- `成年银发猫耳女性，白色客厅，午后窗边坐着`
- `成年猫耳女性，雏菊湖岸，清晨，浅蓝连衣裙`
- `成年女性，旧书房，夕阳，奶油针织开衫`
- `成年白发猫耳女性，奶油客厅，午后沙发坐姿，浅桃裙和象牙针织开衫`
- `黑发成年人类女性，雨夜书店窗边`

按需要补充身份、发色、衣服、动作、时间或画幅即可，无需填满模板。用户给定的要求优先，缺失的搭配作为设计补全，而不是假称来自参考图。选择此 Skill 后按既有节点流程显式「优化」；结果直写提示词并可撤销。确认后由用户另行点击生图，选择或优化 Skill 都不应自动产生图片任务。

### 默认保留与允许变化

- 保留画法、服装材质表达、可信光源和环境构图逻辑，不强制相同人物、发色、兽耳尾巴或脸型。指定人类时不加兽耳，指定男性或其他服装时不套女裙。
- 衣服未指定且适合角色时，从褶皱裙、荷叶边、细蕾丝、小系带、针织开衫或外纱中选相容组合。保持覆盖层不透视，不以增加露肤还原风格。袜装与赤足不是必选。
- 默认人物为成年；明确未成年人时保持年龄，采用适龄、不暴露、非性化服装和姿态。参考图片本身不作为实际年龄证据。
- 默认单人竖幅全身环境图，优先 9:16，头脚留安全边距；显式横构图、近景、多人物或无人场景优先，不强行补人或拉回全身。
- 五种光景是例子，不是只能选的五个场景。换咖啡馆、温室、车站等，仍以实际时间、天气和地点组织主光、环境色与空间层次；不把雏菊、书页、雨滴全部混入每张图。
- 默认生成原输入语言的提示词；用户要求英文／双语才切换。规则本身使用英文，与其它应用内 Skill 保持一致。

## 完整提示词示例

下面是人工编写的目标输出示例，用来说明密度和风格，不是付费模型试跑或画面验收结果。

输入：`成年白发猫耳女性，红眼，奶油客厅，午后沙发坐姿，浅桃裙和象牙针织开衫，白色不透袜装`

> 一位成年白发猫耳女性自然坐在象牙色软包沙发上，红色眼睛是画面中克制的色彩点，神情柔和、轻微歪头，银白发束与几缕飞发沿肩背自然垂落。身穿不透视的浅桃色收腰褶裙，小圆领下系细窄蝴蝶结，腰部拼接与坐姿形成的裙褶清楚；外搭宽松象牙色罗纹针织开衫，袖身有柔软厚度，袖口与衣摆织纹方向可辨，白色不透袜装保持哑光。9:16竖幅环境全身构图，脸位于上三分之一附近，头顶与脚下留出空间；坐垫承托重心，双手自然靠在坐面旁，一腿轻微前伸形成克制的透视纵深，不放大脚部抢占脸部焦点。画面右侧高窗与纱帘过滤午后阳光，为发丝和开衫边缘带来轻薄亮边；浅色沙发、木地板与小边桌构成空间层次，边桌仅放一只杯子。整体为奶油、象牙与浅桃色系，暖灰接触阴影和同向柔和投影保留体积，白发、衣物与沙发用细微明度及冷暖分离，不糊成白色块。细暖灰轮廓、柔和分层上色、精细发束与织物纹理，脸部和领口清晰，背景安静而可读；不使用摄影真人脸、油亮塑料皮肤、粗黑描边或过量泛光，不添加文字水印。

输入：`成年女性，旧书房，夕阳，奶油针织开衫`

> 一位成年女性安静地站在旧书房的高窗旁，柔和的日系二维五官，浅银色长发分成细密发束，几缕发丝随窗边微风轻轻展开；身穿奶油色细褶连衣裙，裙摆为克制的荷叶边，外搭宽松针织开衫，麻花织纹、罗纹袖口与小纽扣清晰，衣身覆盖层不透视。人物身体略向窗外转动，双手自然放松，姿态稳定。9:16竖幅全身环境构图，头顶与脚下保留空间，以窗框和前景盆花轻轻框住画面，中景人物清晰，后方深棕书架、少量打开的书页与木地板构成纵深。夕阳从窗侧形成暖金色主光，发丝边缘透亮，脸部阴影细腻柔和，书架保留安静的深色，不将背景漂白；少量浮尘只在光束里可见。细而浅的线条、柔和分层渐变、克制的纸感与精细织物纹理，整体温暖、安静，人物融入环境，不使用摄影真人脸、塑料三维质感、过量泛光或无关文字水印。

输入：`黑发成年人类女性，雨夜书店窗边，横构图半身`

> 黑发成年人类女性站在雨夜书店窗边，保留人类耳部，不添加兽耳或尾巴，细密黑色发束在窗侧暖光中显出柔和的棕色边缘；身穿不透视的奶油色褶皱衣裙和浅灰针织开衫，布料自然下垂，袖口纹理清晰，神情安静，微微侧身看向窗外。横幅半身环境构图，人物略偏一侧，为窗外雨景留出空间；近处窗框形成框景，中景为人物与木质窗台，后景书架和街道保持清楚的空间关系。玻璃上细小雨痕折射店内局部暖灯，室外蓝灰夜色与湿地反光维持较深明度，暖光只柔和照亮脸侧、发丝和衣褶，不把夜景改成白天。采用精细日系二维插画画法、浅而细的轮廓线、细腻渐变、少量绘画纹理与克制高光，冷暖安静对照，不套仙侠开衩拖尾裙，不出现摄影真人脸、塑料质感或无关字幕水印。

## 能力与验收边界

- Skill 是**文字优化规则**，不是图像风格模型、LoRA、图像识别服务或像素级复刻保证。模型、参考图输入能力和采样都会影响实际图像。
- 五张图的可见规律已经写入规则，使用默认风格不要求再次上传原图。用户后续新传的资源在此流程中仍只给优化模型提供标签和占位符；不能宣称已经看过新图像像素，也不推断没展示的背部或服装连接。
- 资源数量、顺序、版本、绑定元数据保持原合同；优化任务仍是独立文字 Run，现有 JSON 结构不变，不默认追加模型名、画质口号、引擎、供应商 flags 或权重语法。
- 保存恢复、目录与中文说明、资源协议和 Mock 浏览器检查不等于真实模型已经生成相似风格。实际效果验收需用户明确模型、费用与次数后另行进行，不自动调用付费模型。
- 初版验证见 [初版检查点](soft-anime-atmosphere-skill-checkpoint.md)；1.1.0 的验证与恢复位置见 [细化检查点](soft-anime-refinement-checkpoint.md)。
