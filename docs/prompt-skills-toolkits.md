### 可复用字段与不变量

- **资产公共字段：** 名称、类别、来源中的身份／用途、风格、题材、形态／尺度、材质／配色、识别锚点、视图／细节、构图及针对性排除项。角色补五官、发型、服装层级、妆造与配饰；场景补入口、动线、门窗、锚点、方位和光源；道具补结构、持有／使用状态、磨损和尺度参照。未提供年龄、厘米数、朝代或尺寸时标为未知／待确认，不以示例补成事实。
- **跨视图一致：** 同一角色的脸型、比例、发型、服装／配饰不漂移；同一场景只换机位，不移动家具、道路和建筑；道具保持结构／材质／比例。单体资产说明板与剧情动作镜头分开。历史资产额外含服饰妆造、同类／多身份群像；神魔额外含神兽、同种／异种群像，不能通用化为所有题材都需神兽。同种群像前后视图须逐一个体对应，同物种结构统一但个体可区分；异种群像不得互相融合或漏掉原文物种（Q11／Q12:209–241）。
- **剧本结构：** 场次编号 → 地点／日夜／内外 → 人物身份及状态 → 关键道具 → 情绪目的 → 分层音效 → 可拍动作 → 对白／内心独白。三类改编稿 103–109、211 行要求保留原文台词及归属；保留 V.O.／OS 区分、因果、关系变化、关键证据和伏笔，不将心理说明机械变成旁白。
- **镜头结构：** 时间区间、主体与在场人数、场景／道具、景别、机位／焦段、运镜、景深／构图、速度、动作、表情、声音及前后状态。首尾时码连续、不重叠、总长准确；对白留出自然停顿及动作时间。视线与下一镜头目标对应，动作有起点、受力／接触及结果。
- **连续性：** 前镜结尾状态接后镜开场；记录位置、姿态、朝向、情绪、服装、道具／法宝／车马、场景破坏、光照天气与时间。未明确离场的人仍在场，特写不等于其它人消失；损坏不自动修复。多人调度可用带图例的俯视／侧视站位图核对，而不保证模型能精确绘图。
- **题材边界：** 都市用关系距离、微表情和生活道具；历史用礼制、座次、冠服、真实工艺与物理；神魔用已给定的境界、法宝及能量规则。保留用户世界观，未知设定先确认，不默认绑定具体朝代或修炼等级。
