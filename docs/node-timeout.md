# 节点超时设置

管理员在「设置 → AI 连接 → 节点超时时间（毫秒）」填写整数并保存。默认 `900000`（15 分钟），允许范围 `1000` 至 `2147483647` 毫秒。填回 `900000` 后保存即可恢复默认值。

## 作用范围

- 文本、图片、音频的 New API 生成请求使用此超时，包括响应体读取。
- 视频创建、状态查询和内容下载的每次请求使用此超时。未显式配置轮询次数时，视频轮询等待总预算也由此值计算，保留每 30 次递增、最高四倍的退避间隔。等待预算按最后一次完整间隔向上取整；网络请求及持久化耗时另计，因此它不是整个工作流的硬截止时间。
- API 本地执行器和 PostgreSQL/BullMQ Worker 均在开始执行节点时读取当前平台设置；已开始的请求保持原值，排队等待不计入预算。
- 浏览器持续查询服务端最终状态，不再使用固定轮询次数误报长任务超时；离开画布时停止后台查询。超时不自动重复提交收费生成；已有视频平台任务 ID 保留用于恢复。
- 模型目录刷新、测试连接以及独立讯飞适配器不读取该设置。讯飞适配器默认请求超时同样为 15 分钟，可由适配器选项覆盖。

## 登录状态校验

登录恢复和续期不使用节点生成超时设置。Canvas API 的 `/v1/auth/me` 在返回前会逐组同步 New API 授权与目录；Web 对会话校验、续期及 401 后的恢复读取使用 180 秒预算，并合并同一认证状态下并发的恢复请求。浏览器不会因此自动重发生成请求。若仍提示超时，应检查 Canvas API、数据库和上游同步链路；仅确认 New API 首页可访问不足以证明这条链路正常。

## 部署覆盖

`NEW_API_TIMEOUT_MS` 是 API 与 Worker 的部署级覆盖值，优先于页面设置。需要允许页面配置生效时，移除该环境变量并重启对应服务。无数据库的独立 Worker 使用环境变量或 15 分钟默认值；本地文件设置由 API 本地执行器读取。

`NEW_API_VIDEO_MAX_POLL_ATTEMPTS` 若显式设置，则优先控制视频轮询次数，可能比页面时间更早结束。未设置时自动根据超时和 `NEW_API_VIDEO_POLL_INTERVAL_MS`（默认 `2000`）计算；默认 15 分钟对应 158 次轮询，等待约 904 秒。

## API 与存储兼容性

`GET /v1/settings/ai` 的 `settings.timeoutMs` 返回当前平台设置；`PATCH /v1/settings/ai` 接受可选整数 `timeoutMs`。省略表示保留现值，恢复默认必须显式提交 `900000`。权限沿用 AI 设置管理员权限。

本地加密设置文件增加可选 `timeoutMs`。PostgreSQL 使用现有 `AiCredential.defaultModels` JSON 中的内部 `__timeoutMs` 字段保存非默认值，HTTP 的 `defaultModels` 不返回该字段。旧文件、旧 JSON 无需迁移，缺少字段时使用默认值。没有数据库结构或凭据格式迁移。

部署前可备份设置文件或数据库。回滚到旧代码前，将自定义超时恢复默认，使 JSON 移除内部扩展字段；旧代码无法识别该扩展，可能忽略同一 JSON 内的默认模型。凭据与用户资源不受影响。
